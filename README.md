# 📝 Smart Todo 

A modern Todo application built with **Nuxt 3 + Nuxt UI + Tailwind CSS**.

## 🚀 Features

* ✅ Add / Delete / Complete Todos
* 🔍 Filter (All / Active / Completed)
* 💾 Persistent state using `localStorage`
* 📊 Custom animated progress bar
* 🎨 Glassmorphism premium UI
* 🌗 Dark mode support
* 🔔 Toast notifications

---

## 🧠 Tech Stack

* **Nuxt 3**
* **Vue 3 (Composition API + TypeScript)**
* **Tailwind CSS**
* **Nuxt UI**
* **LocalStorage (Client Persistence)**

---





## 💾 State Persistence

Todos are stored in `localStorage`:

* Loaded on mount
* Synced automatically using a deep `watch()`

No Pinia required.

---



Combined with gradient fills:

```css
bg-gradient-to-r from-indigo-600/80 to-blue-600/80
```

## 🛠 Installation

```bash
git clone <your-repo-url>
cd smart-todo
npm install
npm run dev
```

## 📦 Build for Production
